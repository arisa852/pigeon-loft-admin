# 鴿舍管理後台

鴿會後台的「鴿舍清單」頁面，包含左側導覽選單、搜尋、排序、刪除確認、查看與編輯彈窗，並支援手機、平板與桌機的響應式版面。

- **線上預覽**：（部署後補上 Vercel 網址）
- **原始碼**：本 repository

---

## 技術選型

| 項目      | 選擇                                        |
| --------- | ------------------------------------------- |
| 框架      | Vue 3（`<script setup>` + Composition API） |
| 建置工具  | Vite                                        |
| 樣式      | Tailwind CSS v4（`@tailwindcss/vite`）      |
| UI 元件庫 | 無，所有元件與樣式皆為手寫                  |

不使用 Element Plus、Ant Design 等元件庫，是為了完整呈現版面切版、元件設計與互動細節的實作能力。

---

## 功能

- **左側導覽選單**：由資料陣列驅動，具 Active 狀態；1024px 以下收合為抽屜選單
- **鴿舍清單**：20 筆測試資料，經緯度以度分秒格式顯示
- **即時搜尋**：可依名稱、編號、地址搜尋，忽略前後空白與大小寫
- **欄位排序**：編號、名稱、創建時間，點擊循環切換「升冪 → 降冪 → 原始順序」；手機版以下拉選單排序
- **刪除確認**：彈窗確認後刪除，並以提示訊息回饋
- **查看彈窗**：顯示單筆完整資料，經緯度同時呈現度分秒與十進位原始值
- **編輯彈窗**：可編輯名稱與地址，名稱為必填
- **刷新**：還原資料、清除搜尋與排序
- **空狀態**：區分「查無搜尋結果」與「目前沒有資料」

## 設計決策

### 資料設計

- **編號 `code` 使用字串**：保留前導零（如 `0000`），存成數字會變成 `0`。
- **經緯度存十進位，顯示時才轉為度分秒**：資料與呈現分離，數值可用於排序、計算與未來的地圖串接。轉換函式 `formatDMS()` 處理了秒數四捨五入後等於 60 的進位問題。
- **創建時間存 ISO 8601**：中文時間字串（如「下午7:30」）無法正確排序。顯示時以 `toLocaleString('zh-TW', { timeZone: 'Asia/Taipei' })` 格式化，避免瀏覽器時區不同造成顯示錯誤。
- **序號不存入資料**：序號是畫面上的列號，由 `index + 1` 產生，搜尋與刪除後自動重新編號。
- **測試資料使用 JSON**：模擬後端 API 回傳格式，未來串接 API 時只需將 import 改為請求，元件邏輯不需修改。

### 元件與狀態管理

- 狀態放在需要它的元件的**共同父層**：目前頁面 `activeKey` 放在 `App`；搜尋、排序與資料放在 `LoftPage`。
- 遵循 **Props 向下、Events 向上**：`LoftTable` 只負責顯示傳入的資料，不自行讀取資料來源。
- 頁面持有原始資料的**複本**（`ref([...loftsData])`），刪除與編輯不影響原始資料，因此刷新可以還原。
- `v-for` 的 `:key` 一律使用 `id`，不使用 index。

### 搜尋與排序

- 資料流為 `lofts → filteredLofts（搜尋）→ sortedLofts（排序）`，兩層 `computed` 串接，每層只做一件事。
- 排序前先複製陣列，因為 `.sort()` 會修改原陣列，`computed` 不應修改來源資料。
- 各欄位比較方式不同：編號以字串比較、名稱以 `localeCompare(..., 'zh-Hant')` 依繁體中文規則排序、時間以 `Date` 數值比較。
- 手機版下拉選單使用**可寫入的 `computed`**，與表頭排序共用同一份狀態。

### 響應式設計（RWD）

| 寬度          | 導覽       | 內容               |
| ------------- | ---------- | ------------------ |
| 768px 以下    | 抽屜選單   | 卡片列表           |
| 768 ～ 1023px | 抽屜選單   | 表格（可橫向捲動） |
| 1024px 以上   | 固定側邊欄 | 表格               |

- 平板直向寬度不足以同時容納側邊欄與 8 欄表格，因此側邊欄在 1024px 以下收合。
- 手機版將表格改為卡片，避免一次只能看到 3～4 欄。
- 使用 `h-dvh` 而非 `h-screen`，避免手機瀏覽器網址列造成高度計算錯誤。
- 手機上輸入框使用 16px 字級，避免 iOS Safari 點擊輸入框時自動放大畫面。

### 互動與無障礙

- 所有互動元素皆有 hover 與 `focus-visible` 狀態，可完整以鍵盤操作。
- 使用語意化標籤：`aside`、`nav`、`header`、`main`、`table` / `th scope`、`dl` / `dt` / `dd`、`form` / `label`。
- 選單使用 `aria-current`；抽屜按鈕使用 `aria-expanded` 與 `aria-controls`；排序表頭使用 `aria-sort`。
- 彈窗使用 `Teleport`、`role="dialog"`、`aria-modal`，支援 ESC 關閉並在開啟時移動焦點。
- 提示訊息使用 `role="status"`，螢幕報讀器可讀出操作結果。

## 實作範圍說明

依題目「設計版面」的要求完成畫面，並額外實作上述互動功能。以下項目為刻意的取捨：

| 項目                         | 說明                                                                       |
| ---------------------------- | -------------------------------------------------------------------------- |
| 添加鴿舍、導入鴿舍、下載模板 | 版面展示，未串接功能                                                       |
| 編輯範圍                     | 開放名稱與地址。編號涉及唯一性驗證、座標涉及格式轉換與範圍驗證，本次未開放 |
| 刪除與編輯                   | 僅作用於目前畫面；點擊「刷新」會重新載入原始資料                           |
| 搜尋按鈕                     | 採即時搜尋，故省略                                                         |
| 分頁                         | 測試資料為 20 筆，未實作                                                   |
| 序號排序                     | 序號為顯示列號，排序後恆為 1、2、3…，故不提供排序                          |
| 其他選單頁面                 | 顯示「此功能開發中」                                                       |

## 專案結構

```
src/
├── data/
│   └── loft.json          # 20 筆測試資料
├── utils/
│   └── formatters.js      # formatDMS、formatDateTime
├── components/
│   ├── AppSidebar.vue     # 左側導覽與手機抽屜
│   ├── LoftToolbar.vue    # 標題、操作按鈕、搜尋
│   ├── LoftTable.vue      # 表格（平板以上）與卡片（手機）
│   └── BaseModal.vue      # 共用彈窗
├── views/
│   └── LoftPage.vue       # 鴿舍清單頁：資料、搜尋、排序、彈窗狀態
├── App.vue                # 整體 Layout
└── main.js
```
